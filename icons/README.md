# Own icons

Put a square PNG here to replace an app's icon on Glasshouse Home, then run the installer again.

The file names come from `ICONS` in `lg-common.html`. Out of the box there is one entry:

| App ID | File |
| --- | --- |
| `youtube.leanback.v4` (YouTube) | `youtube.png` |

To add another app, add a line to `ICONS` with its app ID and a file name, and put that file here.

No icons are included, because app logos belong to their owners. If a file is missing, the app keeps its own icon.

Use a square picture of 256×256 or larger. The tile's colour is taken from the picture's edge, so a solid background around the logo works best.
